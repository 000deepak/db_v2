## 2. Concatenation Operator

| Operator | Description |   |                        |
| -------- | ----------- | - | ---------------------- |
| `        |             | ` | Joins strings together |

### Example

```sql
SELECT 'Hi ' || ENAME
FROM EMP
WHERE JOB = 'MANAGER';
```

**Output**

| ENAME     |
| --------- |
| Hi ALLEN  |
| Hi MARTIN |
| Hi SMITH  |

## 5. Logical Operators

| Operator | Description                 |
| -------- | --------------------------- |
| `AND`    | All conditions must be true |
| `OR`     | Any condition can be true   |
| `NOT`    | Negates a condition         |

### Examples

#### Employees working as Manager in Dept 10

```sql
SELECT ENAME, DEPTNO, JOB
FROM EMP
WHERE JOB = 'MANAGER'
  AND DEPTNO = 10;
```

#### Employees earning between 1250 and 3000

```sql
SELECT ENAME, SAL
FROM EMP
WHERE SAL > 1250
  AND SAL < 3000;
```

#### Employees working in Dept 10 or 20

```sql
SELECT ENAME, DEPTNO
FROM EMP
WHERE DEPTNO = 10
   OR DEPTNO = 20;
```

## 6. Special Operators

| Operator      | Description                   |
| ------------- | ----------------------------- |
| `IN`          | Checks multiple values        |
| `NOT IN`      | Excludes multiple values      |
| `BETWEEN`     | Checks values within a range  |
| `NOT BETWEEN` | Checks values outside a range |
| `IS NULL`     | Checks for NULL values        |
| `IS NOT NULL` | Checks for non-NULL values    |
| `LIKE`        | Pattern matching              |
| `NOT LIKE`    | Opposite of LIKE              |

## IN Operator

**Definition:** Multi-valued operator that accepts multiple values on the RHS.

### Syntax

```sql
column_name IN (value1, value2, ..., valueN)
```

### Example

```sql
SELECT ENAME, DEPTNO
FROM EMP
WHERE DEPTNO IN (10, 30);
```

```sql
SELECT ENAME, JOB
FROM EMP
WHERE JOB IN ('CLERK', 'MANAGER', 'SALESMAN');
```

---

## NOT IN Operator

**Definition:** Opposite of `IN`; excludes specified values.

### Syntax

```sql
column_name NOT IN (value1, value2, ..., valueN)
```

### Example

```sql
SELECT ENAME, DEPTNO
FROM EMP
WHERE DEPTNO NOT IN (10, 40);
```

```sql
SELECT ENAME, DEPTNO
FROM EMP
WHERE DEPTNO = 20
  AND JOB NOT IN ('CLERK', 'MANAGER');
```

---

## BETWEEN Operator

**Definition:** Used for a range of values. Includes both start and end values.

### Syntax

```sql
column_name BETWEEN lower_value AND upper_value
```

### Example

```sql
SELECT ENAME, SAL
FROM EMP
WHERE SAL BETWEEN 1000 AND 3000;
```

```sql
SELECT ENAME, DEPTNO
FROM EMP
WHERE DEPTNO = 10
  AND HIREDATE BETWEEN '01-JAN-2019'
                   AND '31-DEC-2019';
```

---

## NOT BETWEEN Operator

**Definition:** Opposite of `BETWEEN`.

### Syntax

```sql
column_name NOT BETWEEN lower_value AND upper_value
```

### Example

```sql
SELECT ENAME, SAL
FROM EMP
WHERE SAL NOT BETWEEN 1000 AND 3000;
```

## LIKE Operator

**Definition:** Used for pattern matching.

### Wildcards

| Wildcard | Description                               |
| -------- | ----------------------------------------- |
| `%`      | Any number of characters (including zero) |
| `_`      | Exactly one character                     |

### Syntax

```sql
column_name LIKE 'pattern'
```

### Examples

#### Starts with 'S'

```sql
SELECT *
FROM EMP
WHERE ENAME LIKE 'S%';
```

#### Ends with 'S'

```sql
SELECT *
FROM EMP
WHERE ENAME LIKE '%S';
```

#### Contains 'S'

```sql
SELECT *
FROM EMP
WHERE ENAME LIKE '%S%';
```

#### Starts with 'J' and ends with 'S'

```sql
SELECT ENAME
FROM EMP
WHERE ENAME LIKE 'J%S';
```

#### Second character is 'A'

```sql
SELECT ENAME
FROM EMP
WHERE ENAME LIKE '_A%';
```

#### Second character is 'A' and last character is 'S'

```sql
SELECT ENAME
FROM EMP
WHERE ENAME LIKE '_A%S';
```

#### Contains at least two 'A's

```sql
SELECT ENAME
FROM EMP
WHERE ENAME LIKE '%A%A%';
```

#### Starts and ends with 'A'

```sql
SELECT ENAME
FROM EMP
WHERE ENAME LIKE 'A%A';
```

#### Salary ends with 50

```sql
SELECT ENAME
FROM EMP
WHERE SAL LIKE '%50';
```

#### Employees hired in November

```sql
SELECT ENAME
FROM EMP
WHERE HIREDATE LIKE '%NOV%';
```

---

## NOT LIKE Operator

### Syntax


### Example


## 7. Subquery Operators

| Operator     | Description                                   |
| ------------ | --------------------------------------------- |
| `ALL`        | Compares with all values returned by subquery |
| `ANY`        | Compares with any value returned by subquery  |
| `EXISTS`     | Returns TRUE if subquery returns rows         |
| `NOT EXISTS` | Returns TRUE if subquery returns no rows      |

```sql
-- EXISTS
SELECT *
FROM EMP E
WHERE EXISTS (
    SELECT 1
    FROM DEPT D
    WHERE D.DEPTNO = E.DEPTNO
);

-- NOT EXISTS
SELECT *
FROM DEPT D
WHERE NOT EXISTS (
    SELECT 1
    FROM EMP E
    WHERE E.DEPTNO = D.DEPTNO
);
```


**5. BETWEEN and NOT BETWEEN**
```sql
SELECT colname1,
       colname2
FROM tablename
WHERE colanme1 
BETWEEN value1 AND value2;

SELECT colname1,
       colname2
FROM tablename
NOT WHERE colanme1 
BETWEEN value1 AND value2;
```
Note: The BETWEEN operator is treated differently in different databases!

In some databases, persons with the LastName of "Hansen" or "Pettersen" will not be listed,
because the BETWEEN operator only selects fields that are between and excluding the test values.

In other databases, persons with the LastName of "Hansen" or "Pettersen" will be listed, because
the BETWEEN operator selects fields that are between and including the test values.

And in other databases, persons with the LastName of "Hansen" will be listed, but "Pettersen" will
not be listed (like the example above), because the BETWEEN operator selects fields between the test values, including the first test value and excluding the last test value.
Therefore: Check how your database treats the BETWEEN operator.

**6. IN and NOT IN**
```sql
SELECT colname1,
       colname2
FROM tablename
WHERE colanme1 
NOT IN (1,2,3,4,5);

SELECT colname1,
       colname2
FROM tablename
WHERE colanme1 
IN (1,2,3,4,5);

SELECT colname1,
       colname2
FROM tablename
WHERE colanme1 % 2 != 1; -- odd numbers
```

**7. CASE: return bases on condition**
```sql
SELECT colname
  CASE 
    WHEN colname = 1 THEN 'one'
    WHEN colname = 2 THEN 'two'
    ELSE 'many'
  END AS COUNTING
FROM tablename; 
```
