# MULTI-ROW FUNCTIONS

A function is a block of code or list of instructions used to perform a specific task. There are 3 main components of a function:

1. **Function_Name**
2. **Number_of_arguments** (number of inputs)
3. **Return type**

## Types of Functions in SQL

### 1. Single Row Functions
- Takes N number of inputs and generates N number of outputs.
- Takes all inputs and executes, generating output one by one.

### 2. Multi Row Functions / Aggregate / Group Functions
- Takes all inputs at one shot, executes, and provides a **single output**.
- If we pass `n` number of inputs to a Multi Row Function, it returns **1 output**.

---

## List of Multi Row Functions

| Function | Description |
|----------|-------------|
| `MAX()`  | Obtains the maximum value present in a column |
| `MIN()`  | Obtains the minimum value present in a column |
| `SUM()`  | Obtains the summation of values present in a column |
| `AVG()`  | Obtains the average of values present in a column |
| `COUNT()`| Obtains the number of values present in a column |

---

## Important Notes

- Multi Row Functions can accept only **one argument**, i.e., a `Column_Name` or an `Expression`.
  ```
MRF(Column_Name / Expression)
  ```
- Along with a Multi Row Function, we are **not supposed to use any other column_name** in the SELECT clause.
- Multi Row Functions **ignore NULL values**.
- We **cannot use a Multi Row Function in the WHERE clause**.
- `COUNT()` is the only Multi Row Function that can accept `*` as an argument.

---

## Examples

### 1. WAQTD maximum salary given to a manager.
```sql
SELECT MAX(SAL) FROM EMP WHERE JOB = 'MANAGER';
```

### 2. WAQTD total salary given to dept 10.
```sql
SELECT SUM(SAL) FROM EMP WHERE DEPTNO = 10;
```

### 3. WAQTD number of employees earning more than 1500 in dept 20.
```sql
SELECT COUNT(*) FROM EMP WHERE SAL > 1500 AND DEPTNO = 20;
```

### 4. WAQTD number of employees having 'E' in their names.
```sql
SELECT COUNT(*) FROM EMP WHERE ENAME LIKE '%E%';
```

### 5. WAQTD minimum salary given to employees working as clerk in Dept 10 or 20.
```sql
SELECT MIN(SAL) FROM EMP WHERE JOB = 'CLERK' AND DEPTNO IN (10, 20);
```

### 6. WAQTD number of employees hired after 1982 and before 1985 into Dept 10 or 30.
```sql
SELECT COUNT(*) FROM EMP 
WHERE HIREDATE > '31-DEC-1982' 
  AND HIREDATE < '01-JAN-1985' 
  AND DEPTNO IN (10, 30);
```

### 7. WAQTD number of employees getting commission.
```sql
SELECT COUNT(*) FROM EMP WHERE COMM IS NOT NULL;
-- Alternative:
SELECT COUNT(COMM) FROM EMP;
```

### 8. WAQTD maximum salary given to employees if the employee has character 'S' in the name, works as a Manager in dept 10, with salary more than 1800.
```sql
SELECT MAX(SAL) FROM EMP 
WHERE ENAME LIKE '%S%' 
  AND JOB = 'MANAGER' 
  AND DEPTNO = 10 
  AND SAL > 1800;
```

### 9. WAQTD number of employees working in dept 10 or 30, getting commission, without salary.
```sql
SELECT COUNT(*) FROM EMP 
WHERE DEPTNO IN (10, 30) 
  AND COMM IS NOT NULL 
  AND SAL IS NULL;

-- Alternative:
SELECT COUNT(COMM) FROM EMP 
WHERE DEPTNO IN (10, 30) 
  AND SAL IS NULL;
```

### 10. WAQTD maximum salary given to a manager working in dept 20, and also his commission must be greater than his salary.
```sql
SELECT MAX(SAL) FROM EMP 
WHERE JOB = 'MANAGER' 
  AND DEPTNO = 20 
  AND COMM > SAL;
```
