In MongoDB, a **cursor** is an object that points to the result set of a query and allows you to retrieve documents **one at a time** or in batches instead of loading all results into memory at once.

### Example

```javascript
const cursor = db.users.find({ age: { $gte: 18 } });
```

Here, `find()` does **not** immediately return all matching documents. It returns a **cursor**.

### Using a Cursor

#### Iterate through documents

```javascript
const cursor = db.users.find();

while (cursor.hasNext()) {
    printjson(cursor.next());
}
```

#### Convert to an array

```javascript
const users = db.users.find().toArray();
```

This loads all matching documents into memory.

### Why Cursors Are Important

* **Efficient memory usage**: Results are fetched in batches.
* **Handles large datasets**: You don't need to load millions of documents at once.
* **Supports pagination**: Use methods like `skip()` and `limit()`.

### Common Cursor Methods

| Method      | Description                         |
| ----------- | ----------------------------------- |
| `next()`    | Returns the next document           |
| `hasNext()` | Checks if more documents exist      |
| `limit(n)`  | Limits number of returned documents |
| `skip(n)`   | Skips specified documents           |
| `sort()`    | Sorts results                       |
| `toArray()` | Converts all results to an array    |
| `forEach()` | Iterates over all documents         |
