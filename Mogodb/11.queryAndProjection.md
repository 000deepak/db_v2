In this example:

```javascript
db.users.findOne({ "username": "john_doe" })
```

Only the **query** is provided.

### Syntax

```javascript
db.collection.findOne(query, projection)
```

* **1st parameter** → `query`
* **2nd parameter** → `projection` (optional)

### Your example

```javascript
db.users.findOne({ "username": "john_doe" })
```

Here:

* **Query:**

  ```javascript
  { "username": "john_doe" }
  ```

  This tells MongoDB to find the first document where the `username` field is `"john_doe"`.


## Example with projection

Suppose you only want the `username` and `email` fields:

```javascript
db.users.findOne(
    { "username": "john_doe" },      // Query
    { "username": 1, "email": 1 }    // Projection
)
```

Result:

```javascript
{
    "_id": ObjectId("123"),
    "username": "john_doe",
    "email": "john@example.com"
}
```

> Notice that `_id` is included by default.

If you don't want `_id`:

```javascript
db.users.findOne(
    { "username": "john_doe" },
    { "_id": 0, "username": 1, "email": 1 }
)
```

Result:

```javascript
{
    "username": "john_doe",
    "email": "john@example.com"
}
```

### Interview tip

* **Query** answers **"Which document(s) should MongoDB find?"**
* **Projection** answers **"Which fields from those document(s) should MongoDB return?"**
