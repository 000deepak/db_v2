# SUBQUERY

A query written inside another query is known as a **subquery**.


| Type            | Returns                          | Example Operator        |
| --------------- | -------------------------------- | ----------------------- |
| Single-row      | One row                          | `=`, `>`, `<`           |
| Multiple-row    | Multiple rows                    | `IN`, `ANY`, `ALL`      |
| Multiple-column | Multiple columns                 | `(col1, col2) IN (...)` |
| Correlated      | Depends on outer query           | References outer table  |
| Nested          | Subquery inside another subquery | Multiple levels         |


## Working Principle

Inner Query executes first and produces an output. The output of the Inner Query is fed as input to the Outer Query. The Outer Query then generates the result. Therefore, the Outer Query is dependent on the Inner Query.

## Why / When Do We Use Subqueries?

### Case 1: Unknown values in the same table

Whenever we have unknowns present in the question, we use a subquery to find the unknown.

**Example Table: EMP**

| EID | ENAME | SAL | DEPTNO |
|-----|-------|-----|--------|
| 1   | ALLEN | 1000| 20     |
| 2   | BLAKE | 2000| 10     |
| 3   | CLARK | 3000| 30     |
| 4   | MILLER| 1500| 10     |
| 5   | SMITH | 2500| 10     |

1. WAQTD names of the employees earning more than 2500.
```sql
SELECT ENAME FROM EMP WHERE SAL > 2500;
```

2. WAQTD names of the employees earning less than MILLER.
```sql
SELECT ENAME FROM EMP WHERE SAL < (SELECT SAL FROM EMP WHERE ENAME = 'MILLER');
```

3. WAQTD name and deptno of the employees working in the same Dept as SMITH.
```sql
SELECT ENAME, DEPTNO FROM EMP WHERE DEPTNO = (SELECT DEPTNO FROM EMP WHERE ENAME = 'SMITH');
```

4. WAQTD name and hiredate of the employees if the employee was hired after JONES.
```sql
SELECT ENAME, HIREDATE FROM EMP WHERE HIREDATE > (SELECT HIREDATE FROM EMP WHERE ENAME = 'JONES');
```

5. WAQTD all the details of the employee working in the same designation as KING.
```sql
SELECT * FROM EMP WHERE JOB = (SELECT JOB FROM EMP WHERE ENAME = 'KING');
```

6. WAQTD name, sal, deptno of the employees earning more than 2000 and working in the same dept as JAMES.
```sql
SELECT ENAME, SAL, DEPTNO FROM EMP WHERE SAL > 2000 AND DEPTNO = (SELECT DEPTNO FROM EMP WHERE ENAME = 'JAMES');
```

7. WAQTD all the details of the employees working in the same designation as MILLER and earning more than 1500.
```sql
SELECT * FROM EMP WHERE SAL > 1500 AND JOB = (SELECT JOB FROM EMP WHERE ENAME = 'MILLER');
```

8. WAQTD details of the employees earning more than SMITH but less than KING.
```sql
SELECT * FROM EMP WHERE SAL > (SELECT SAL FROM EMP WHERE ENAME = 'SMITH') AND SAL < (SELECT SAL FROM EMP WHERE ENAME = 'KING');
```

9. WAQTD name, sal and deptno of the employees earning commission in dept 20 and earning salary more than SCOTT.
```sql
SELECT ENAME, SAL, DEPTNO FROM EMP WHERE COMM IS NOT NULL AND DEPTNO = 20 AND SAL > (SELECT SAL FROM EMP WHERE ENAME = 'SCOTT');
```

10. WAQTD name and hiredate of the employees whose name ends with 's' and hired after JAMES.
```sql
SELECT ENAME, HIREDATE FROM EMP WHERE ENAME LIKE '%S' AND HIREDATE > (SELECT HIREDATE FROM EMP WHERE ENAME = 'JAMES');
```

11. WAQTD names of the employees working in the same dept as JAMES, earning more than ADAMS, same job as MILLER, and hired after MARTIN.
```sql
SELECT ENAME FROM EMP 
WHERE DEPTNO = (SELECT DEPTNO FROM EMP WHERE ENAME = 'JAMES')
  AND SAL > (SELECT SAL FROM EMP WHERE ENAME = 'ADAMS')
  AND JOB = (SELECT JOB FROM EMP WHERE ENAME = 'MILLER')
  AND HIREDATE > (SELECT HIREDATE FROM EMP WHERE ENAME = 'MARTIN');
```

12. WAQTD all details of employees working as salesman in dept 20, earning commission more than SMITH, and hired after KING.
```sql
SELECT * FROM EMP 
WHERE JOB = 'SALESMAN' 
  AND DEPTNO = 20 
  AND COMM > (SELECT COMM FROM EMP WHERE ENAME = 'SMITH')
  AND HIREDATE > (SELECT HIREDATE FROM EMP WHERE ENAME = 'KING');
```

13. WAQTD number of employees earning more than SMITH and less than MARTIN.
```sql
SELECT COUNT(*) FROM EMP 
WHERE SAL > (SELECT SAL FROM EMP WHERE ENAME = 'SMITH')
  AND SAL < (SELECT SAL FROM EMP WHERE ENAME = 'MARTIN');
```

14. WAQTD Ename and SAL for all employees earning more than JONES.
```sql
SELECT ENAME, SAL FROM EMP WHERE SAL > (SELECT SAL FROM EMP WHERE ENAME = 'JONES');
```

15. WAQTD all details of employees working as a manager.
```sql
SELECT * FROM EMP WHERE JOB = 'MANAGER';
```

> **Note:** In the Inner Query / Sub Query we cannot select more than **one column**. The corresponding columns need not be the same, but their datatypes must be the same.

## Single Row vs Multi Row Subquery

### Single Row Subquery
If the subquery returns exactly **1 record/value**, we call it a Single Row Subquery. Normal operators (`=`, `>`, `<`, etc.) or special operators can be used.

### Multi Row Subquery
If the subquery returns **more than 1 record/value**, we call it a Multi Row Subquery. Normal operators cannot be used; only special operators (`ALL`, `ANY`, `IN`, etc.) are allowed.

> **Note:** It is difficult to know beforehand whether a subquery is Single or Multi row, so it is always recommended to use **Special Operators** to compare values.

**Example: WAQTD ename and salary of employees earning more than employees of dept 10.**

| EID | ENAME | SAL | DEPTNO |
|-----|-------|-----|--------|
| 1   | ALLEN | 1000| 20     |
| 2   | BLAKE | 2000| 10     |
| 3   | CLARK | 3000| 30     |
| 4   | MILLER| 1500| 10     |
| 5   | SMITH | 2500| 10     |

## Special Operators

### ALL
Used with a relational operator (`>`, `<`, `>=`, `<=`) to compare with all values on the RHS. `ALL` returns true if **all** RHS values satisfy the condition.

#### Examples:
- `1000 > ALL (2000, 1500, 2500)` → false
- `2000 > ALL (2000, 1500, 2500)` → false
- `3000 > ALL (2000, 1500, 2500)` → true
- `1500 > ALL (2000, 1500, 2500)` → false
- `2500 > ALL (2000, 1500, 2500)` → false

### ANY
Used with a relational operator. `ANY` returns true if **at least one** RHS value satisfies the condition.

#### Examples:
- `1000 > ANY (2000, 1500, 2500)` → false
- `2000 > ANY (2000, 1500, 2500)` → true
- `3000 > ANY (2000, 1500, 2500)` → true
- `1500 > ANY (2000, 1500, 2500)` → false
- `2500 > ANY (2000, 1500, 2500)` → true

**Query examples:**

1. WAQTD name of the employee if the employee earns less than **all** employees working as salesman.
```sql
SELECT ENAME FROM EMP WHERE SAL < ALL (SELECT SAL FROM EMP WHERE JOB = 'SALESMAN');
```

2. WAQTD name of the employee if the employee earns less than **at least one** salesman.
```sql
SELECT ENAME FROM EMP WHERE SAL < ANY (SELECT SAL FROM EMP WHERE JOB = 'SALESMAN');
```

3. WAQTD names of the employees earning more than ADAMS.
```sql
SELECT ENAME FROM EMP WHERE SAL > ALL (SELECT SAL FROM EMP WHERE ENAME = 'ADAMS');
```

## Nested Subqueries for Nth Maximum/Minimum

3. WAQTD maximum salary.
```sql
SELECT MAX(SAL) FROM EMP;
```

4. WAQTD second maximum salary.
```sql
SELECT MAX(SAL) FROM EMP WHERE SAL < (SELECT MAX(SAL) FROM EMP);
```

5. WAQTD 3rd maximum salary.
```sql
SELECT MAX(SAL) FROM EMP 
WHERE SAL < (SELECT MAX(SAL) FROM EMP 
             WHERE SAL < (SELECT MAX(SAL) FROM EMP));
```

6. WAQTD 4th maximum salary.
```sql
SELECT MAX(SAL) FROM EMP 
WHERE SAL < (SELECT MAX(SAL) FROM EMP 
             WHERE SAL < (SELECT MAX(SAL) FROM EMP 
                          WHERE SAL < (SELECT MAX(SAL) FROM EMP)));
```

7. WAQTD 3rd minimum salary.
```sql
SELECT MIN(SAL) FROM EMP 
WHERE SAL > (SELECT MIN(SAL) FROM EMP 
             WHERE SAL > (SELECT MIN(SAL) FROM EMP));
```

8. WAQTD Dept name of the employee getting 2nd minimum salary.
```sql
SELECT DNAME FROM DEPT 
WHERE DEPTNO = (SELECT DEPTNO FROM EMP 
                WHERE SAL = (SELECT MIN(SAL) FROM EMP 
                             WHERE SAL > (SELECT MIN(SAL) FROM EMP)));
```

| Remember |        |
|----------|--------|
| MAXIMUM  | MAX()  |
| MINIMUM  | MIN()  |
