Below are the **most important MongoDB Aggregation operators** with **short examples** using the `employees` collection.



# 1. `$match`

Filter documents (similar to `WHERE`).

```javascript
db.employees.aggregate([
    { $match: { department: "IT" } }
])
```



# 2. `$project`

Select or create fields (similar to `SELECT`).

```javascript
db.employees.aggregate([
    {
        $project: {
            name: 1,
            salary: 1,
            city: "$address.city",
            _id: 0
        }
    }
])
```



# 3. `$group`

Group documents (similar to `GROUP BY`).

```javascript
db.employees.aggregate([
    {
        $group: {
            _id: "$department",
            totalEmployees: { $sum: 1 }
        }
    }
])
```



# 4. `$sort`

Sort documents.

```javascript
db.employees.aggregate([
    { $sort: { salary: -1 } }
])
```



# 5. `$limit`

Return first N documents.

```javascript
db.employees.aggregate([
    { $limit: 5 }
])
```



# 6. `$skip`

Skip first N documents.

```javascript
db.employees.aggregate([
    { $skip: 5 }
])
```



# 7. `$unwind`

Split array into multiple documents.

```javascript
db.employees.aggregate([
    { $unwind: "$skills" }
])
```



# 8. `$count`

Count documents.

```javascript
db.employees.aggregate([
    { $match: { active: true } },
    { $count: "ActiveEmployees" }
])
```



# 9. `$addFields`

Add a new field.

```javascript
db.employees.aggregate([
    {
        $addFields: {
            bonus: 5000
        }
    }
])
```



# 10. `$unset`

Remove field.

```javascript
db.employees.aggregate([
    {
        $unset: "salary"
    }
])
```



# 11. `$replaceRoot`

Replace root document.

```javascript
db.employees.aggregate([
    {
        $replaceRoot: {
            newRoot: "$address"
        }
    }
])
```



# 12. `$lookup`

Join another collection.

```javascript
db.employees.aggregate([
    {
        $lookup: {
            from: "departments",
            localField: "department",
            foreignField: "department",
            as: "deptInfo"
        }
    }
])
```



# 13. `$facet`

Run multiple aggregations together.

```javascript
db.employees.aggregate([
    {
        $facet: {
            ITEmployees: [
                { $match: { department: "IT" } }
            ],
            HighSalary: [
                { $match: { salary: { $gt: 90000 } } }
            ]
        }
    }
])
```



# 14. `$bucket`

Group salary ranges.

```javascript
db.employees.aggregate([
    {
        $bucket: {
            groupBy: "$salary",
            boundaries: [0, 70000, 100000, 150000],
            default: "Other"
        }
    }
])
```



# 15. `$sample`

Random documents.

```javascript
db.employees.aggregate([
    { $sample: { size: 3 } }
])
```



# 16. `$sortByCount`

Count by field.

```javascript
db.employees.aggregate([
    {
        $sortByCount: "$department"
    }
])
```



# 17. `$merge`

Write output to another collection.

```javascript
db.employees.aggregate([
    {
        $merge: "employee_backup"
    }
])
```



# 18. `$out`

Store result in another collection.

```javascript
db.employees.aggregate([
    { $match: { department: "IT" } },
    { $out: "it_employees" }
])
```



# Common Accumulators (Used with `$group`)

### `$sum`

```javascript
db.employees.aggregate([
    {
        $group: {
            _id: "$department",
            totalSalary: { $sum: "$salary" }
        }
    }
])
```



### `$avg`

```javascript
db.employees.aggregate([
    {
        $group: {
            _id: "$department",
            averageSalary: { $avg: "$salary" }
        }
    }
])
```



### `$min`

```javascript
db.employees.aggregate([
    {
        $group: {
            _id: "$department",
            minimumSalary: { $min: "$salary" }
        }
    }
])
```



### `$max`

```javascript
db.employees.aggregate([
    {
        $group: {
            _id: "$department",
            maximumSalary: { $max: "$salary" }
        }
    }
])
```



### `$push`

```javascript
db.employees.aggregate([
    {
        $group: {
            _id: "$department",
            employees: { $push: "$name" }
        }
    }
])
```



### `$addToSet`

```javascript
db.employees.aggregate([
    {
        $group: {
            _id: "$department",
            uniqueManagers: { $addToSet: "$manager" }
        }
    }
])
```



### `$first`

```javascript
db.employees.aggregate([
    { $sort: { salary: 1 } },
    {
        $group: {
            _id: "$department",
            firstEmployee: { $first: "$name" }
        }
    }
])
```



### `$last`

```javascript
db.employees.aggregate([
    { $sort: { salary: 1 } },
    {
        $group: {
            _id: "$department",
            lastEmployee: { $last: "$name" }
        }
    }
])
```



### `$count` (Accumulator)

```javascript
db.employees.aggregate([
    {
        $group: {
            _id: "$department",
            employees: { $count: {} }
        }
    }
])
```



# Date Operators

### `$year`

```javascript
db.employees.aggregate([
    {
        $project: {
            name: 1,
            year: { $year: "$joiningDate" }
        }
    }
])
```



### `$month`

```javascript
db.employees.aggregate([
    {
        $project: {
            name: 1,
            month: { $month: "$joiningDate" }
        }
    }
])
```



### `$dayOfMonth`

```javascript
db.employees.aggregate([
    {
        $project: {
            name: 1,
            day: { $dayOfMonth: "$joiningDate" }
        }
    }
])
```



## Most Important Aggregation Stages (Interview)

| Stage             | Purpose                  |
| -- |  |
| `$match`          | Filter documents         |
| `$project`        | Select/rename fields     |
| `$group`          | Group documents          |
| `$sort`           | Sort results             |
| `$limit`          | Return first N documents |
| `$skip`           | Skip N documents         |
| `$unwind`         | Flatten arrays           |
| `$lookup`         | Join collections         |
| `$facet`          | Multiple pipelines       |
| `$bucket`         | Group into ranges        |
| `$sample`         | Random documents         |
| `$count`          | Count documents          |
| `$addFields`      | Add computed fields      |
| `$unset`          | Remove fields            |
| `$merge` / `$out` | Save aggregation results |

These are the aggregation stages and accumulators most commonly asked in MongoDB interviews.
