## 1. LENGTH()

It is used to count the number of characters present in the given string.

**Syntax:** `LENGTH('string')`

### Examples

```sql
-- WAQT count number of characters present in 'SMITH'
SELECT LENGTH(ENAME) FROM EMP WHERE ENAME = 'SMITH';

SELECT LENGTH('SMITH') FROM DUAL;

SELECT LENGTH('HELLO WORLD') FROM DUAL;  -- returns 11
```

> **NOTE: DUAL TABLE**
> It is a dummy table which has 1 column and 1 row. It is used to output the result.
> ```sql
> DESC DUAL;
> SELECT * FROM DUAL;
> ```

## 2. CONCAT()

It is used to join two given strings.

**Syntax:** `CONCAT('string1', 'string2')`

### Example

Input: `Smith` → Output: `Mr. Smith`


## 7. SUBSTR()

It is used to extract a part of a string from the given original string.

**Syntax:** `SUBSTR('Original_String', Position [, Length])`

### Position reference (example with 'QSPIDER')

| -ve | -7 | -6 | -5 | -4 | -3 | -2 | -1 |
|-----|----|----|----|----|----|----|----|
| +ve | 1  | 2  | 3  | 4  | 5  | 6  | 7  |
|     | Q  | S  | P  | I  | D  | E  | R  |

### Examples

| Example | Output |
|---------|--------|
| `SUBSTR('QSPIDER', 2, 3)` | SPI |
| `SUBSTR('QSPIDER', 3, 3)` | PID |
| `SUBSTR('QSPIDER', 2)` | SPIDER |
| `SUBSTR('QSPIDER', 1, 6)` | QSPIDE |
| `SUBSTR('QSPIDER', 4, 1)` | I |
| `SUBSTR('QSPIDER', 1, 1)` | Q |
| `SUBSTR('QSPIDER', 7, 1)` | R |
| `SUBSTR('QSPIDER', 6)` | ER |
| `SUBSTR('QSPIDER', 0, 3)` | QSP |
| `SUBSTR('QSPIDER', 6, 6)` | ER |
| `SUBSTR('QSPIDER', -2, 1)` | E |
| `SUBSTR('QSPIDER', -5, 3)` | PID |
| `SUBSTR('QSPIDER', -7, 2)` | QS |
| `SUBSTR('QSPIDER', -1)` | R |

### Query Examples

```sql
-- WAQT extract first 3 characters of the emp names
SELECT SUBSTR(ENAME, 1, 3) FROM EMP;

-- WAQT extract last 3 characters of the employee names
SELECT SUBSTR(ENAME, -3) FROM EMP;

-- WAQT to display first half of employee names
-- ENAME: SMITH → SM, MILLER → MIL, JONES → JO, WARD → WA
SELECT SUBSTR(ENAME, 1, LENGTH(ENAME) / 2) FROM EMP;

-- WAQT to display second half of employee names
-- ENAME: SMITH → ITH, MILLER → LER, JONES → NES, WARD → RD
SELECT SUBSTR(ENAME, LENGTH(ENAME) / 2 + 1) FROM EMP;
```

## 8. REPLACE()

It is used to replace a string with another string in the original string.

**Syntax:** `REPLACE('Original_String', 'string' [, 'new_String'])`

### Examples

1. WAQTD the number of times char 'A' is present in 'BANANA'.
   ```sql
   SELECT LENGTH('BANANA') - LENGTH(REPLACE('BANANA', 'A')) FROM DUAL;
   -- 6 - LENGTH('BNN') = 6 - 3 = 3
   ```

2. WAQTD to count number of times 'A' is present in 'MALAYALAM'.
   ```sql
   SELECT LENGTH('MALAYALAM') - LENGTH(REPLACE('MALAYALAM', 'A')) FROM DUAL;
   ```

## 9. INSTR()

It is used to obtain the position in which a string is present in the original string. It searches for a string; if present, it returns the position, else returns 0.

**Syntax:** `INSTR('Original_String', 'String', Position [, Occurrence])`

> **Note:** If occurrence is not mentioned, the default value of occurrence is 1.

### Examples with 'BANANA'

| Expression | Result |
|------------|--------|
| `INSTR('BANANA', 'A', 1, 1)` | 2 |
| `INSTR('BANANA', 'A', 2, 1)` | 2 |
| `INSTR('BANANA', 'A', 1, 2)` | 4 |
| `INSTR('BANANA', 'A', 1, 3)` | 6 |
| `INSTR('BANANA', 'A', 1, 4)` | 0 |
| `INSTR('BANANA', 'A', 4, 2)` | 6 |

### Query Examples

```sql
-- 1. WAQTD names of the employees if they have char 'A' present in their names
SELECT ENAME FROM EMP WHERE INSTR(ENAME, 'A', 1, 1) > 0;

-- 2. WAQTD names of the employees if they have char 'A' at least twice in their names
SELECT ENAME FROM EMP WHERE INSTR(ENAME, 'A', 1, 2) > 0;

-- 3. WAQTD names of the employees if they have char 'A' at least thrice in their names
SELECT ENAME FROM EMP WHERE INSTR(ENAME, 'A', 1, 3) > 0;

-- 4. WAQTD names of the employees if they have char 'A' exactly twice
SELECT ENAME FROM EMP 
WHERE INSTR(ENAME, 'A', 1, 2) > 0 
  AND INSTR(ENAME, 'A', 1, 3) = 0;

-- OR using LENGTH and REPLACE
SELECT ENAME FROM EMP 
WHERE (LENGTH(ENAME) - LENGTH(REPLACE(ENAME, 'A'))) = 2;
```

## 11. ROUND()

It is used to round off the given number based on the scale value.

**Syntax:** `ROUND(Number [, Scale])` (Default scale is 0)

### Examples

| Expression | Result |
|------------|--------|
| `ROUND(5.6)` | 6 |
| `ROUND(5.5)` | 6 |
| `ROUND(5.4)` | 5 |
| `ROUND(9.9)` | 10 |
| `ROUND(9.4)` | 9 |
| `ROUND(8.6, 0)` | 9 |

- When scale is **negative**, it indicates digits before the decimal (digit count begins from 1).
- When scale is **positive**, it indicates digits after the decimal (digit count begins from 0).

| Expression | Result |
|------------|--------|
| `ROUND(124.3541, 0)` | 124 |
| `ROUND(124.3541, 1)` | 124.2 |
| `ROUND(123.671263, 6)` | 123.671264 |

---

## 12. TRUNC()

It is similar to `ROUND()` but always rounds down to the lower value.

**Syntax:** `TRUNC(Number [, Scale])`

### Examples

| Expression | Result |
|------------|--------|
| `TRUNC(5.6)` | 5 |
| `TRUNC(5.5)` | 5 |
| `TRUNC(5.4)` | 5 |
| `TRUNC(9.9)` | 9 |
| `TRUNC(9.4)` | 9 |
| `TRUNC(8.6, 0)` | 8 |
| `TRUNC(1258.32541, -5)` | 400000 |

## Date Commands

| Function | Description |
|----------|-------------|
| `SYSDATE` | Obtains today's date |
| `CURRENT_DATE` | Also obtains today's date |
| `SYSTIMESTAMP` | Obtains date, time, and time zone |

## 15. TO_CHAR()

It is used to convert a given date into string format based on the format model.

**Syntax:** `TO_CHAR(DATE, 'Format_Models')`

### Format Models

| Model | Description | Example |
|-------|-------------|---------|
| `YEAR` | Year in words | TWENTY TWENTY |
| `YYYY` | 4-digit year | 2020 |
| `YY` | 2-digit year | 20 |
| `MONTH` | Full month name | JULY |
| `MON` | Abbreviated month | JUL |
| `MM` | Month number | 07 |
| `DAY` | Full day name | WEDNESDAY |
| `DY` | Abbreviated day | WED |
| `DD` | Day of month | 08 |
| `D` | Day of week (1-7) | 4 |
| `HH24` | Hour (24-hour) | 17 |
| `HH12` | Hour (12-hour) | 5 |
| `MI` | Minutes | 22 |
| `SS` | Seconds | 53 |
| `'HH12:MI:SS'` | Time format | 5:22:53 |
| `'DD-MM-YY'` | Date format | 17-05-20 |
| `'MM-DD-YYYY'` | Date format | 05-17-2020 |

### Query Examples

```sql
-- 1. WAQTD details of the employee who was hired on a SUNDAY
SELECT * FROM EMP WHERE TO_CHAR(HIREDATE, 'DAY') = 'SUNDAY';

-- 2. WAQTD details of an employee hired on MONDAY at 10 AM
SELECT * FROM EMP 
WHERE TO_CHAR(HIREDATE, 'D') = 2 
  AND TO_CHAR(HIREDATE, 'HH24') = 10;
```

## 16. NVL() (Null Value Logic)

It is used to eliminate the side effects of using NULL in arithmetic operations.

**Syntax:** `NVL(Argument1, Argument2)`

- **Argument1:** Any column/expression that can result in NULL.
- **Argument2:** A numeric value substituted if Argument1 results in NULL. If Argument1 is NOT NULL, its original value is used.

### Example

```sql
SELECT ENAME, SAL + NVL(COMM, 0) FROM EMP;
```

| ENAME | Calculation | Result |
|-------|-------------|--------|
| A     | 500 + NVL(100, 0) = 500 + 100 | 600 |
| B     | 1000 + NVL(NULL, 0) = 1000 + 0 | 1000 |
| C     | 2000 + NVL(200, 0) = 2000 + 200 | 2200 |
| D     | 2000 + NVL(NULL, 0) = 2000 + 0 | 2000 |

-- OR

SELECT DNAME FROM DEPT WHERE INSTR(DNAME, 'O', 1, 1) != 0;

-- 11. Display all employees whose job contains 'MAN'
SELECT * FROM EMP WHERE INSTR(JOB, 'MAN', 1, 1) != 0;

-- 12. Display all employees whose job starts with 'MAN'
SELECT * FROM EMP WHERE INSTR(JOB, 'MAN', 1, 1) = 1;
-- OR
SELECT * FROM EMP WHERE SUBSTR(JOB, 1, 3) = 'MAN';

-- 13. Display all employees whose job ends with 'MAN'

SELECT * FROM EMP 
WHERE TO_CHAR(HIREDATE, 'DY') = 'SUN' 
  AND TO_CHAR(HIREDATE, 'MON') = 'MAY';
