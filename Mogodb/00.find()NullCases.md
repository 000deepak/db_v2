In **Spring Boot** with MongoDB, the `find()` method **never returns `null`** directly. Here's what actually happens:

## For `MongoTemplate.find()`

```java
List<User> users = mongoTemplate.find(query, User.class);
// Returns an EMPTY LIST (never null) if no data found
```

## For `MongoRepository.findAll()` or custom `findBy...()`

```java
List<User> users = userRepository.findAll();
// Returns an EMPTY LIST (never null)

List<User> users = userRepository.findByName("John");
// Returns an EMPTY LIST (never null)
```

## Special Cases (Optional return types)

```java
// Using Optional - returns Optional.empty()
Optional<User> user = userRepository.findById("123");
// Not null, but Optional.empty()

// Using @Query with single result
@Query("{'name': ?0}")
User findByName(String name);
// Returns NULL if no data found (for single object)
```

## Summary Table

| Method Return Type | No Data Found | Returns Null? |
|-------------------|---------------|---------------|
| `List<T>` | Empty List `[]` | ❌ No |
| `Optional<T>` | `Optional.empty()` | ❌ No |
| Single Object (T) | `null` | ✅ Yes |
| `Page<T>` | Empty Page | ❌ No |
| `Stream<T>` | Empty Stream | ❌ No |

## Best Practice Example

```java
// For Lists - always check isEmpty()
List<User> users = userRepository.findAll();
if (!users.isEmpty()) {
    // Process users
}

// For Optional - use orElse() or orElseThrow()
User user = userRepository.findById("123")
    .orElseThrow(() -> new RuntimeException("User not found"));

// For single object - check for null
User user = userRepository.findByEmail("test@email.com");
if (user != null) {
    // Process user
}
```
