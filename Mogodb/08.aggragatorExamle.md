
# 1. `$match`

Filter documents (similar to `WHERE`).

```javascript
db.employees.aggregate([
    { $match: { department: "IT" } }
])
```



# 2. `$project`
Select or create fields (similar to `SELECT`).

```javascript
db.employees.aggregate([
    {
        $project: {
            name: 1,
            salary: 1,
            city: "$address.city",
            _id: 0
        }
    }
])
```



# 3. `$group`
- Syntax
```javascript
db.collection.aggregate([
  {
    $group: {
      _id: <field_to_group_by>,
      <newField>: { <accumulator>: <expression> }
    }
  }
])
```
* `_id` → The field you want to group by (similar to `GROUP BY` in SQL).
* Accumulators like `$sum`, `$avg`, `$max`, `$min`, `$push`, etc., calculate values for each group.

- Group by Name
```javascript
db.employees.aggregate([
  {
    $group: {
      _id: "$name"
    }
  }
])
//output    
[
  { "_id": "John" },
  { "_id": "Emma" },
  { "_id": "David" }

```

- Count Employees with Same Name
```sql
SELECT name, COUNT(*)
FROM employees
GROUP BY name;
```

```javascript
db.employees.aggregate([
  {
    $group: {
      _id: "$name",
      count: { $sum: 1 }
    }
  }
])
```

- Group by Name and Department
```sql
SELECT name, department, COUNT(*)
FROM employees
GROUP BY name, department;
```

```javascript
db.employees.aggregate([
  {
    $group: {
      _id: {
        name: "$name",
        department: "$department"
      },
      count: {
        $sum: 1
      }
    }
  }
])
```

# lookup
used to **join documents from two collections**, similar to an **SQL JOIN**.

**SQL equivalent:**
```sql
SELECT *
FROM orders o
JOIN customers c
ON o.customerId = c.id;
```

**MongoDB equivalent:**
```javascript
db.orders.aggregate([
  {
    $lookup: {
      from: "customers",
      localField: "customerId",
      foreignField: "_id",
      as: "customer"
    }
  }
])
```
* **from** → Collection to join with.
* **localField** → Field in the current collection.
* **foreignField** → Matching field in the other collection.
* **as** → Name of the output array containing matched documents.


```javascript
//Customers Collection
db.customers.insertMany([
  { _id: 1, name: "John", city: "Mumbai" },
  { _id: 2, name: "Alice", city: "Pune" }
]);


//Orders Collection
db.orders.insertMany([
  { _id: 101, item: "Laptop", customerId: 1 },
  { _id: 102, item: "Phone", customerId: 2 },
  { _id: 103, item: "Mouse", customerId: 1 }
]);

//join
db.orders.aggregate([
  {
    $lookup: {
      from: "customers",
      localField: "customerId",
      foreignField: "_id",
      as: "customerDetails"
    }
  }
]);

//Output
[
  {
    _id: 101,
    item: "Laptop",
    customerId: 1,
    customerDetails: [
      {
        _id: 1,
        name: "John",
        city: "Mumbai"
      }
    ]
  },
  {
    _id: 102,
    item: "Phone",
    customerId: 2,
    customerDetails: [
      {
        _id: 2,
        name: "Alice",
        city: "Pune"
      }
    ]
  },
  {
    _id: 103,
    item: "Mouse",
    customerId: 1,
    customerDetails: [
      {
        _id: 1,
        name: "John",
        city: "Mumbai"
      }
    ]
  }
]
```

```javascript
    from: "otherCollection",
    localField: "fieldInCurrentCollection",
    foreignField: "fieldInOtherCollection",
    as: "outputArray"
  }
}
```

# 5. `$limit`

Return first N documents.

```javascript
db.employees.aggregate([
    { $limit: 5 }
])
```



# 6. `$skip`

Skip first N documents.

```javascript
db.employees.aggregate([
    { $skip: 5 }
])
```



# 7. `$unwind`

Split array into multiple documents.

```javascript
db.employees.aggregate([
    { $unwind: "$skills" }
])
```



# 8. `$count`

Count documents.

```javascript
db.employees.aggregate([
    { $match: { active: true } },
    { $count: "ActiveEmployees" }
])
```



# 9. `$addFields`

Add a new field.

```javascript
db.employees.aggregate([
    {
        $addFields: {
            bonus: 5000
        }
    }
])
```



# 10. `$unset`

Remove field.

```javascript
db.employees.aggregate([
    {
        $unset: "salary"
    }
])
```

# 12. `$lookup`

Join another collection.

```javascript
db.employees.aggregate([
    {
        $lookup: {
            from: "departments",
            localField: "department",
            foreignField: "department",
            as: "deptInfo"
        }
    }
])
```

# Common Accumulators (Used with `$group`)

### `$sum`

```javascript
db.employees.aggregate([
    {
        $group: {
            _id: "$department",
            totalSalary: { $sum: "$salary" }
        }
    }
])
```



### `$avg`

```javascript
db.employees.aggregate([
    {
        $group: {
            _id: "$department",
            averageSalary: { $avg: "$salary" }
        }
    }
])
```



### `$min`

```javascript
db.employees.aggregate([
    {
        $group: {
            _id: "$department",
            minimumSalary: { $min: "$salary" }
        }
    }
])
```



### `$max`

```javascript
db.employees.aggregate([
    {
        $group: {
            _id: "$department",
            maximumSalary: { $max: "$salary" }
        }
    }
])
```



### `$push`

```javascript
db.employees.aggregate([
    {
        $group: {
            _id: "$department",
            employees: { $push: "$name" }
        }
    }
])
```



### `$addToSet`

```javascript
db.employees.aggregate([
    {
        $group: {
            _id: "$department",
            uniqueManagers: { $addToSet: "$manager" }
        }
    }
])
```



### `$first`

```javascript
db.employees.aggregate([
    { $sort: { salary: 1 } },
    {
        $group: {
            _id: "$department",
            firstEmployee: { $first: "$name" }
        }
    }
])
```



### `$last`

```javascript
db.employees.aggregate([
    { $sort: { salary: 1 } },
    {
        $group: {
            _id: "$department",
            lastEmployee: { $last: "$name" }
        }
    }
])
```



### `$count` (Accumulator)

```javascript
db.employees.aggregate([
    {
        $group: {
            _id: "$department",
            employees: { $count: {} }
        }
    }
])
```




### `$dayOfMonth`

```javascript
db.employees.aggregate([
    {
        $project: {
            name: 1,

])
```



## Most Important Aggregation Stages (Interview)

| Stage             | Purpose                  |
| -- |  --|
| `$match`          | Filter documents         |
| `$project`        | Select/rename fields     |
| `$group`          | Group documents          |
| `$sort`           | Sort results             |
| `$limit`          | Return first N documents |
| `$skip`           | Skip N documents         |
| `$unwind`         | Flatten arrays           |
| `$lookup`         | Join collections         |
| `$facet`          | Multiple pipelines       |
| `$bucket`         | Group into ranges        |
| `$sample`         | Random documents         |
| `$count`          | Count documents          |
| `$addFields`      | Add computed fields      |
| `$unset`          | Remove fields            |
| `$merge` / `$out` | Save aggregation results |
