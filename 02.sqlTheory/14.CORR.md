# CO-RELATED SUBQUERY

A query written inside another query such that the outer query and the inner query are **dependent on each other** is known as a **Co-Related Subquery**.

## Working Principle

1. Outer query executes **first but partially**.
2. The partially executed output is given as an input to the inner query.
3. The inner query executes **completely** and generates an output.
4. The output of the inner query is fed as input to the outer query, and the outer query produces the result.
5. Therefore, the outer query and the inner query are **interdependent** (dependent on each other).

> **Notes:**
> - In a co-related subquery, a **join condition** is mandatory and must be written only in the inner query.
> - Co-related subquery works with the principles of both **SUBQUERY** and **JOINs**.

---

## Examples

### 1. WAQTD dnames in which there are employees working.

```sql
SELECT DNAME 
FROM DEPT D 
WHERE D.DEPTNO IN (SELECT E.DEPTNO 
                   FROM EMP E 
                   WHERE D.DEPTNO = E.DEPTNO);
```

### 2. WAQTD dname in which there are **no** employees working.

```sql
SELECT DNAME 
FROM DEPT D 
WHERE D.DEPTNO NOT IN (SELECT E.DEPTNO 
                       FROM EMP E 
                       WHERE D.DEPTNO = E.DEPTNO);
```

---

## Difference between SUBQUERY and CO-RELATED SUBQUERY

| SUBQUERY                              | CO-RELATED SUBQUERY                     |
|---------------------------------------|------------------------------------------|
| Inner query executes first            | Outer query executes first               |
| Outer query is dependent on inner query | Both are interdependent                 |
| Join condition not mandatory          | Join condition is mandatory and must be written in inner query |
| Outer query executes once             | Outer query executes twice (or multiple times) |

---

## EXISTS Operator

- `EXISTS` is a **unary operator** (one operand) that accepts one operand on the RHS, and that operand must be a **co-related subquery**.
- `EXISTS` returns **true** if the subquery returns **any value other than NULL**.

---

## NOT EXISTS Operator

- `NOT EXISTS` is also a unary operator.
- It returns **true** if the subquery returns **NULL**.

---

## Finding MAX and MIN Salary using Co-Related Subquery

### To find MAX salary

(Refer to image in original document – typical pattern)

```sql
SELECT SAL FROM EMP E1 
WHERE NOT EXISTS (SELECT 1 FROM EMP E2 WHERE E2.SAL > E1.SAL);
```

### To find MIN salary

```sql
SELECT SAL FROM EMP E1 
WHERE NOT EXISTS (SELECT 1 FROM EMP E2 WHERE E2.SAL < E1.SAL);
```

## Finding Nth Maximum Salary

### To find 3rd maximum salary (N = 3)

```sql
SELECT SAL FROM EMP E1 
WHERE (SELECT COUNT(DISTINCT SAL) 
       FROM EMP E2 
       WHERE E1.SAL < E2.SAL) = 2;
```

### To find 2nd, 4th, 5th, 7th maximum salaries (using IN clause)

```sql
SELECT SAL FROM EMP E1 
WHERE (SELECT COUNT(DISTINCT SAL) 
       FROM EMP E2 
       WHERE E1.SAL < E2.SAL) IN (1, 3, 4, 6);
```

### To find MINIMUM salary using count pattern

```sql
SELECT SAL FROM EMP E1 
WHERE (SELECT COUNT(DISTINCT SAL) 
       FROM EMP E2 
       WHERE E1.SAL >= E2.SAL) = N - 1;
```
*(For minimum, N = 1 gives count = 0)*
